# ENGRAM
**A memory substrate made of mortal beliefs.**

## 1. The thesis
Every approach the prompt disqualifies shares the root failure it names — memory as storage-with-search — but beneath that sits a deeper failure nobody names: **in every existing system, facts are immortal.** A line in CLAUDE.md, a chunk in a vector index, an edge in a knowledge graph — none is *capable of being wrong on its own*. Each persists until a human notices it is wrong and deletes it by hand, and that hand-labor is precisely what the mission says must go to zero. The deleted-function scar is not a retrieval failure. It is a memory in which nothing could die.
Engram inverts the premise: **every belief is born with its death conditions.** A belief that cannot name what would make it false is a rumor, and the format refuses rumors — the linter rejects the file. A fact about auth.ts carries a *watch* on auth.ts (content hash, AST shape of its symbol). The diff that deletes refreshToken() kills the belief at ingest — mechanically, deterministically, no model, no human — and the next briefing carries its obituary instead of its ghost.
Three old machineries, fused: Accounting (append-only journal = book of original entry; beliefs = ledger balances; audit = reading the ledger; nothing erased, status changes, every change journaled); Build systems (beliefs = derived artifacts with declared world-state dependencies; staleness propagates like a dirty bit; reverification = incremental rebuild); Compilers (knowledge compiled ahead of time at multiple resolutions; a briefing = code generation for the context window under a hard size constraint). Novelty = the epistemic contract fusing them: memory as preparation, beliefs mortal, provenance total, read path model-free.

## 2. Object model — four layers, each derived from the one below (delete all but Layer 0 and it regenerates; store = fold(journal))
- Layer 0 — Traces (the journal): immutable evidence events ("at T, principal P observed/told/inferred X from source S"). Session exhaust, diffs, tests, CI, user corrections, and the system's OWN actions land here. Append-only JSONL, one shard per writer, checksummed lines, torn-tail tolerant, never edited/deleted, grep-able. Example: {"t":"2026-07-30T09:14:02Z","seq":8412,"principal":"agent:sess-b31f","event":"diff_applied","subjects":["src/auth/token.ts"],"payload":{"commit":"9c1e4","symbols_removed":["refreshToken"]},"sha":"88ab…"}
- Layer 1 — Engrams (unit of storage; NOT a document): one falsifiable statement + everything to trust/doubt/kill/resurrect it. Markdown + structured frontmatter (new file TYPE with its own linter), cat-readable, git-diffable:
  ---
  id: eg-7f3a91
  kind: observed            # observed | told | inferred | assumed | consolidated
  status: live              # live | stale | disputed | superseded | dead
  confidence: {basis: observed, evidence: 3, reverified: 2026-07-28, disputes: 0}
  watch:
    - {path: src/auth/token.ts, symbol: issueToken, ast-hash: "88ab…"}
    - {horizon: 2027-01-01}
  evidence: [tr-8412, tr-8977, tr-9051]
  lineage: {consolidates: [], superseded-by: null}
  subjects: [auth, token-issuance]
  ---
  Constitutional rule (linter fails the build): NO IMMORTAL BELIEFS — every engram declares ≥1 watch (world-state hash, horizon, or `until: user-denies`) and ≥1 evidence trace. Two lifecycle policies on one substrate: Directives (user-told imperatives, no decay, briefed first, killable only by user) vs Beliefs (descriptive, fully mortal). Confidence is never a naked float — it is a derivation displayed as its inputs (kind base-rate × evidence count × principal trust × reverification recency × dispute history).
- Layer 2 — Dossiers (compiled views): per-subject prose at an ALTITUDE LADDER: A0 one line, A1 paragraph, A2 page, A3 full detail with inline citations. Compiled top-down (A3 first, each level a checked compression of the one below), invariant: every claim at altitude N appears at N+1. Each altitude records measured token cost. Dossiers = cache: dirty-propagated, evictable, rebuildable.
- Layer 3 — The briefing (the product): fixed narrative grammar; every line carries a citation sigil ⟦e:7f3a⟧ resolving engram→traces.
Accounting frame: traces = book of original entry, engrams = ledger balances, dossiers = financial statements, briefing = the one-pager before the meeting.

## 3. Read path — a LINKER, not a search engine
`engram brief <task> --budget N` = pure function f(store snapshot, task descriptor, budget) → briefing; byte-reproducible; zero model calls; zero network. Four stages: (1) Task descriptor: mechanical parse of task text + session opening (files/symbols, paths, verb class fix/build/explain/review, tags). (2) Relevance fold: graph proximity over MECHANICALLY derived edges — no embedding search on read path: subject↔file (repo structure), file↔file (git co-change — free in history), engram↔subject (declared at write), × recency × trust. Embeddings allowed ONLY at compile time to suggest association edges, frozen into an auditable table; read path walks the table, never the embedding space. (3) Packing: knapsack over real measured token costs; budget buys RESOLUTION BEFORE BREADTH; mandatory sections (directives, tripwires in blast radius) funded first. (4) Narrative grammar (fixed order): 1 Standing orders (directives, user's voice) · 2 Tripwires ("Do NOT call refreshToken() — deleted 2026-06-03 ⟦e:9c1⟧") · 3 The situation (task-local, full depth) · 4 Recently deceased (obituaries) · 5 The neighborhood (adjacent, compressed) · 6 Open questions (live disputes, expiring assumptions) · 7 Sigil legend ("interrogate any line with `engram why ⟦sigil⟧`").
Budget monotonicity = HARD guarantee: altitudes are compile-time-checked compressions, so a 4k briefing can never contradict the 200k for the same (snapshot,task) — smaller budget = coarser truth, never different truth. Golden tests enforce it.

## 4. Write path + metabolism
Recording is mechanical and NEVER blocks: adapters turn exhaust (transcripts, commits/diffs, tests, CI, user messages) into traces, no model. Structural beliefs form mechanically (module maps, co-change, churn, ownership, "tests X cover Y," "symbol Z removed in commit C"). Metabolism = where LLM labor is permitted (deferred, budgeted, journaled with model+prompt hashes; `engram why` works on metabolizer decisions). Five processes: (1) Reverification sweep (mechanical, every ingest): fire watchers, live→stale where world moved, auto-revive on cheap checks. (2) Extraction (LLM, budgeted): trace spans→candidate engrams; enters QUARANTINE (kind inferred, single-evidence, capped below A1 until corroborated by a 2nd independent trace or passed reverification) — slop can't reach load-bearing sections. (3) Consolidation (LLM, threshold-triggered): N overlapping engrams→one principle engram citing every absorbed member; absorbed→`consolidated` (out of briefing candidacy, never out of record) — keeps live set ~constant as journal grows unbounded. (4) Contradiction reconciliation: detected mechanically (two live engrams share a watch target, one's evidence postdates the other; or user correction); protocol order: evidence kind (observed>told>inferred>assumed) → recency → principal trust → ESCALATE to dispute record; briefing carries one honest line, never both as truth. (5) Decay: truth never time-decays; what decays is briefing PRIORITY (relevance) and confidence only for perishable kinds; decay demotes, never deletes.
NO-LLM degraded mode: recording, watchers, staleness, structural beliefs, dossier reuse, briefing compilation are all model-free — stops learning from prose, never stops tracking reality (already beats baselines since staleness was the killing failure). Where intelligence lives, defended: write-time = amortized/cached/auditable; read-time = per-use/unrepeatable/unauditable (compilers optimize at build, not run).

## 5. How a belief dies (5 deaths, each journaled + tombstoned + citable)
1 Falsified (watcher fired, reverification failed; tombstone cites killing diff — makes the deleted-function scar structurally impossible). 2 Superseded (lost a contradiction; dispute record links victor/victim). 3 Consolidated (absorbed into a principle — retirement with forwarding address). 4 Expired (born with a horizon, reached it unreverified). 5 Executed (`engram deny <id>`; user is highest court, tombstone records their words). Nothing ever deleted — status changes; journal holds every transition; "auditable forgetting" = reading the obituaries.

## 6. Multi-agent by construction
Principals (every trace carries author: user/agent session/subagent-with-trust-tier/tool; engram trust floor derives from evidence principals; trust = config not vibes). Concurrency without coordination (one journal shard per writer — appends never contend; deterministic fold by (timestamp, session id); compilation/metabolism under a single lease; kill -9 costs at most one torn trailing line in one shard, skipped by fold). Disagreement = an event with a protocol (dispute record, same ladder, escalates to briefing as open question, never silently picks a winner, never blocks on a human). Team vs private (separate stores, overlay semantics — private mounts over team; precedence declared in a file; facts resolve toward team, preferences toward private; cross-store conflicts = ordinary dispute records). Sync (the store IS a git repo — team distribution/offline/history on existing infra).

## 7. Persistence — boring on purpose
Reinvention budget spent entirely on FORMAT + LIFECYCLE (mortal beliefs, epistemic frontmatter, altitude ladders, linter); durability borrowed from battle-tested machinery. Canonical state = plain text in a git repo (journal shards *.trace.jsonl, engram files, dossier sources); `git log --follow` on an engram = its history; "what did we believe about auth on May 1" = `git show`. Derived state disposable (relevance tables, watcher indexes, token-cost tables in a rebuildable gitignored cache — SQLite or sorted flats; deleting it costs a recompile, never knowledge). The journal is the only sacred object. Auditable at rest: every layer inspectable with cat/grep/git, no proprietary tooling. Deployment: v1 = library + CLI + hooks, NO daemon (a daemon must earn residency); v2+ = resident metabolizer holding the lease, eventually a VFS where `cat .engram/brief/fix-auth@4k.md` compiles on open. Argued, deferred, not needed to win.

## 8. Mandatory questions answered
Belief death = 5 ways (§5). Day 1 / 10 entries: `engram init` bootstraps mechanically from git history alone (module map, co-change, churn, ownership, test topology) — useful in minute one, no LLM; linker admits everything at low altitude, well-ordered beats voluminous (mechanism: mechanical bootstrap). Year 3 / 1M entries: journal grows linearly but COLD (never read on hot path); consolidation keeps live set ~constant; briefings IMPROVE with scale (principles carry more collateral) (mechanism: consolidation pressure). 4k vs 200k: altitude, never truncation; 4k = airport briefing (every relevant subject one line, all tripwires/obituaries/open-questions); 200k = war-room binder (A3 dossiers, inline citations, full disputes, verbatim journal); monotone consistency compile-time-enforced. Interface (chosen from how models actually behave — read files natively, follow briefing-embedded instructions better than tool descriptions, waste tokens on chatty tools): FOUR VERBS + the files — `engram brief`, `engram why`, `engram tell`, `engram sync`; MCP wrapper exposing the same four; dossiers on disk to cat deeper. Deliberately NO query language (knowing-what-to-ask-for is the system's job). Intelligence: read path none (constitutionally); record time none; metabolism LLM permitted/budgeted/journaled(model+prompt hashes)/optional. Unit of storage: the engram (one mortal falsifiable statement + epistemics/watchers/evidence/lineage); documents are compiled VIEWS.
Not-the-3-disqualified: no similarity search on read path, a linker over precompiled views ranked by mechanical relevance ≠ RAG-with-metadata; materialized fold of a journaled belief state with mortality+provenance, briefing compiled not concatenated ≠ CLAUDE.md-with-folders; meaning in mortal prose statements not edges, edges only for packing, no model ever consumes the graph ≠ knowledge-graph-but-smaller.

## 9. The scars, closed
Deleted-function call → watchers killed the belief at ingest of the deleting diff; briefing carries obituary + tripwire; measured as stale-reference rate (§10). Two memory files contradicted, both loaded → one belief state; contradictions become dispute records; a briefing structurally can't carry two live contradictory engrams — one honest open-question line. RAG surfaces a 2-year-old README → nothing enters a briefing without `live` status; README engrams watched the README and died with it. Deploy process explained 40 times → `engram tell` once → a directive (no decay, user's voice, funded first forever); the 41st explanation is one line atop every session. The other user (the agent) designed for throughout: linear-read narrative grammar, tripwires before temptation, actionable citations (`engram why`), real-token budgets, briefings that admit uncertainty.

## 10. v1, the proof, the plan
Dogfood target: THIS repo (Round Table — real git history AND real agent-session logs in .round-table/) + one external OSS repo (anti-overfit). Replay benchmark (named in PRD, committed): replay history to time T; take ≥20 real post-T tasks; produce fixed-budget briefings from (a) Engram, (b) grep-pack (best scripted grep-over-files), (c) naive RAG at same budget; run same agent same task with each; score downstream task success, tokens, references to symbols nonexistent at T, questions memory could have answered. Committed numbers (v1 ships iff): success-per-context-token @8k ≥ 1.25× better baseline; stale-reference rate ≤ 0.1× either baseline; 100% of briefing lines resolve via `engram why` to traces; byte-identical briefings across 100 repeated compiles of same (snapshot,task,budget); warm brief p95 ≤ 300ms; cold fold of 1M-trace journal ≤ 60s on a laptop. Milestones (each gated): M0 Format freeze + mechanical bootstrap. M1 The mortality engine (watchers/staleness/tombstones/obituaries/tripwires/`engram deny`; ships first, no model; gate: deleted-function scar unreproducible). M2 The linker (descriptor/relevance fold/knapsack-by-altitude/grammar/sigils/`engram why`; gate: byte-reproducibility + budget-monotonicity goldens). M3 The metabolizer (extraction+quarantine/consolidation+total-citation/contradiction protocol/confidence derivations, journaled w/ model+prompt hashes; gate: full suite passes with LLM disabled; consolidation holds live set flat across a synthetic year). M4 Many hands (writer shards/metabolizer lease/team overlay over git remote/cross-principal disputes; gate: chaos suite — kill -9 mid-append, concurrent sessions — zero corruption/loss). M5 The proof (replay benchmark on both repos; publish vs committed numbers or account for misses). Risks owned + non-goals refused on principle (no query language; no read-path embeddings ever; no write-path LLM; no automatic deletion ever; no cross-repo global brain in v1; no omniscient truth-arbitration).

## 11. Closing
The database for agentic use was never a faster index. Agents don't lack recall — they lack a STATE OF MIND: held beliefs, with provenance, that die when the world changes and admit it when they conflict. Engram is that state of mind as an artifact. Immortal facts rot. Mortal beliefs stay true.
